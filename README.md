Essa experiência acabou moldando bastante a forma como desenvolvo software hoje: gosto de **entender o problema antes de escrever código**, organizar bem as regras de negócio e construir soluções que façam sentido para quem vai utilizá-las.

# Projetos em destaque

## [OUR COMMIT](https://github.com/enthonydev/OUR-COMMIT)

**Transforme seu `git diff` em uma mensagem de commit melhor.**

CLI em TypeScript que analisa as alterações preparadas em staging e utiliza **Anthropic ou OpenAI** para sugerir mensagens seguindo o padrão Conventional Commits.

O desenvolvedor mantém o controle: por padrão, a ferramenta apenas sugere a mensagem. O commit só é criado quando solicitado explicitamente.

`TypeScript` `Node.js` `Git` `Anthropic API` `OpenAI API`

**Destaques:** CLI · integração com LLMs · Conventional Commits · abstração de providers

[Ver projeto →](https://github.com/enthonydev/OUR-COMMIT)

---

## [REAL BALANCE ROOM — RBR](https://github.com/enthonydev/REAL-BALANCE-ROOM-rbr.)

**Simulação e análise de financiamentos imobiliários.**

Aplicação para comparar os sistemas **Price e SAC**, calcular cronogramas financeiros e analisar o impacto de amortizações extraordinárias no prazo, nas parcelas, nos juros e no saldo devedor.

O projeto separa o motor financeiro da interface e da persistência, permitindo validar as regras de negócio através de testes automatizados.

`React` `TypeScript` `Express` `SQLite` `Vitest` `CI`

**Destaques:** regras financeiras · arquitetura full stack · testes automatizados · persistência · CI

[Ver projeto →](https://github.com/enthonydev/REAL-BALANCE-ROOM-rbr.)

## [REST Event Management API](https://github.com/enthonydev/REST-Event-Management-API)

**Backend para gerenciamento de eventos, ingressos, produtos e pedidos.**

API REST criada como laboratório de desenvolvimento backend, trabalhando autenticação, validação de dados, regras de disponibilidade e cálculo de pedidos no servidor.

Inclui testes HTTP e de regras de negócio, documentação OpenAPI e estrutura preparada para persistência com PostgreSQL e Prisma.

`Node.js` `TypeScript` `Express` `Zod` `JWT` `Vitest` `OpenAPI`

**Destaques:** REST API · autenticação · validação · testes · documentação de contrato · CI

[Ver projeto →](https://github.com/enthonydev/REST-Event-Management-API)

## [Estação Meteorológica Inteligente](https://github.com/enthonydev/PROJETO-ESTACAO-METEOROLOGICA)

**Projeto IoT para coleta, transmissão e visualização de dados ambientais.**

Arquitetura baseada em **ESP32 + MicroPython**, com telemetria MQTT, backend FastAPI, persistência PostgreSQL e dashboard web.

O projeto é desenvolvido academicamente em etapas, mantendo documentação de arquitetura, contrato de telemetria versionado, testes de software e CI.

`ESP32` `MicroPython` `MQTT` `Python` `FastAPI` `PostgreSQL`

**Destaques:** IoT · arquitetura distribuída · telemetria · contrato de dados · backend · CI

> Projeto em desenvolvimento — as etapas atuais possuem validação em software; integração completa com o hardware físico ainda está em andamento.

[Ver projeto →](https://github.com/enthonydev/PROJETO-ESTACAO-METEOROLOGICA)
